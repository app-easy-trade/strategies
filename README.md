# НИР: гибридный новостной парсер финансовых событий

Репозиторий содержит код и артефакты НИР по теме автоматической обработки коротких финансовых новостей. Проект собирает публичные сообщения MarketTwits из web-версии Telegram, нормализует их и превращает в структурированные события: тема новости, связанные компании/тикеры, рыночные инструменты, направление влияния, обоснование и проверяемые цитаты.

Практическая цель НИР — получить воспроизводимый прототип новостного парсера, который можно использовать как первый слой мониторинга для торговой или аналитической системы. Парсер не принимает инвестиционные решения, а готовит проверяемые признаки для дальнейшей фильтрации, ручной аналитики и notebook-исследований.

## Быстрый запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 run_all.py --offline --limit 40
```

После запуска результаты будут сохранены в `output/`.

## Режимы работы

По умолчанию проект запускается в детерминированном offline-режиме: ключи API не нужны, а классификация выполняется локальными правилами, RAG-контекстом и инструментами.

Для запуска с LLM скопируйте `.env.example` в `.env`, поставьте `OFFLINE=0` и заполните один из вариантов:

- `OPENAI_API_KEY` и `LLM_MODEL`;
- или `LLM_BASE_URL`, `LLM_AUTH_TOKEN`, `LLM_MODEL`.

Затем выполните:

```bash
python3 run_all.py --limit 40
```

## Что где лежит

- `fetch_markettwits.py` — загрузка публичной web-страницы `https://t.me/s/markettwits`.
- `schema.py` — Pydantic-схемы новостного события, результата анализа и eval-отчета.
- `rag.py` — BM25-поиск по правилам рынка и каталогу компаний.
- `market_tools.py` — инструменты определения тикеров, тем, инструментов, горизонта и влияния.
- `agent.py` — обработка одного поста: RAG, tools, structured output, judge.
- `pipeline.py` — основной прогон корпуса новостей.
- `eval.py` — проверка качества на размеченных примерах.
- `run_all.py` — единая команда для запуска пайплайна и eval.
- `input/` — сохраненный срез постов, каталог компаний, правила рынка и gold-eval.
- `output/` — результаты прогона, сводки, трассы, eval и отчет о галлюцинациях.
- `notebooks/` — исследовательские ноутбуки для анализа сигналов, сделок и рыночного режима.
- `отчёт.md` — текстовый отчет по НИР.

## Логика пайплайна

1. Посты MarketTwits загружаются из `input/posts_sample.json` или обновляются через `fetch_markettwits.py`.
2. Для каждого поста подбирается контекст из `market_rules.md` и `company_catalog.json`.
3. Инструменты ищут компании, тикеры, рыночные инструменты, тему, срочность и направление влияния.
4. Результат собирается в строгую схему `NewsAnalysis`.
5. Judge проверяет цитаты и числа, чтобы не пропустить выдуманные фрагменты.
6. Пайплайн сохраняет `analysis.json`, `analysis.csv`, `summary.json` и `trace.jsonl`.
7. Eval проверяет точность и путь обработки на размеченном наборе из `gold_eval.json`.

## Основные артефакты

- `output/analysis.json` и `output/analysis.csv` — структурированная разметка новостей.
- `output/summary.json` — агрегированная статистика по темам, влиянию, компаниям и стоимости.
- `output/trace.jsonl` — трасса инструментов для аудита каждого решения.
- `output/eval_results.json` и `output/eval_results.csv` — метрики качества.
- `output/hallucination_report.json` — проверка ghost-цитат и ghost-чисел.
- `output/failure_cases.json` — разобранные ошибки и исправления.

## Обновление корпуса

```bash
python3 fetch_markettwits.py --limit 80 --out input/posts_sample.json
python3 run_all.py --offline --limit 40
```

Загрузка использует публичную web-страницу Telegram и не требует Telegram API.
